# Who gets to build with AI?

A single-page, no-build exhibit: a Lego globe where every tower is a country, its height is AI usage per person and its colours are whose models people use. Three.js is loaded as a global from cdnjs; there is no bundler, package.json or framework, and the site is plain static files. `index.html` is markup only and links `styles.css` and the ES-module entry `js/main.js`. `js/` holds the app split by concern: `main.js` (frame loop, intro, init), `scene.js` (Three.js scene, towers, camera, picking, pointer and keyboard input), `panel.js` (side panel, tabs, cards, bottom sheet), `state.js` (shared `state` and `view` objects), `model.js` (the data joined and derived at load), `colors.js` (palettes and the CSS token mirror), `accessGap.js` (the access score), `sfx.js` (sound) and `util.js` (helpers). The figures live in `data/countries.js`, `data/datacentres.js` and `data/continents.js` as plain exported arrays and objects. `tools/` holds the headless Chrome checks (`behaviour-check.js` snapshots what the UI shows, `tower-pick-test.js` checks tower picking) and `serve.js`, the tiny static server they need because module scripts cannot load over `file://`. Hosting is GitHub Pages from the `main` branch with the custom domain in `CNAME`: **push to main deploys**, usually live within a minute. Country figures carry per-field provenance (`data/sources.js`, `data/raw/LICENSES.md`); rebuild them with `node tools/fetch-data.mjs`.
