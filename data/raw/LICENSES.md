# Raw data: sources and terms

Downloaded by `tools/fetch-data.mjs` on 2026-10-18. Each source feeds the provenance objects in `data/countries.js` (keys in `data/sources.js`).

| Folder | Source | What is here | Terms |
|---|---|---|---|
| `worldbank/` | World Bank Indicators API, series IT.NET.USER.ZS (internet users, % of population; the ITU series republished by the World Bank), EG.ELC.ACCS.ZS (access to electricity), NY.GDP.PCAP.CD (GDP per capita, current US$), SP.POP.TOTL (population). API last updated 2026-10-08. | The API responses for all countries, 2010 to date, as returned (`<series>.json`). | [CC BY 4.0](https://datacatalog.worldbank.org/public-licenses#cc-by). Attribution: "World Bank, World Development Indicators". ITU data inside the WDI carry the same WDI terms. |
| `anthropic-economic-index/` | Anthropic Economic Index, release 2026-06-26, file `data/aei_claude_ai_2026-06-26.csv` on [Hugging Face](https://huggingface.co/datasets/Anthropic/EconomicIndex/tree/main/release_2026_06_26). | Only the country-level `usage_per_capita_index` rows (235 rows, April and May 2026). The full 219 MB file is not committed; the script caches it in the OS temp directory. | Data [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), code MIT (dataset README). Cite "Anthropic Economic Index" and the release. The index measures Claude.ai usage share divided by working-age population share: it is a Claude-usage proxy, not all-AI usage. |
| `cable/` | Cable.co.uk, Worldwide Mobile Data Pricing 2023 (`worldwide_mobile_data_pricing_data.xlsx`, exchange rates frozen 7 Sep 2023), from https://www.cable.co.uk/mobiles/worldwide-data-pricing/ | `average_price_1gb_usd_2023.csv`: country code, name, plans measured and average price of 1GB in USD for the countries listed in `data/countries.js` only. The workbook itself is downloaded by the script but **not committed** (`.gitignore`). | **Not an open licence.** Cable.co.uk's site terms (https://www.cable.co.uk/terms/) reserve all rights and forbid compiling a database from the site. The pricing study is published for citation and is quoted widely by press with attribution, which is how this repository uses it: one figure per country, attributed to Cable.co.uk in `data/sources.js`. If you want to be certain, ask Cable.co.uk (info@cable.co.uk) for written permission or replace the series with ITU's ICT price baskets, which are CC BY. |

Not downloaded: there is no public per-country series for monthly active AI users, provider shares, growth curves or city-level usage. Those fields keep their modelled values and are marked `estimated: true`.
